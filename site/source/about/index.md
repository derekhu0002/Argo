## ARGO HARNESS

ARGO 是一个向量知识图谱（GraphRAG）驱动的 Agent Loop 框架，以 ArchiMate 企业架构语言作为知识图谱的结构，覆盖从需求分析、架构设计、开发测试到交付归档的整个软件交付周期。

### 核心特性

- **意图架构图谱** — ArchiMate 3.2 建模，可验证、可追溯的业务与架构事实源
- **Agent Loop 编排** — BusinessPartner → TaskTidy → Orchestrator 阶段闭环
- **GraphRAG 语义检索** — 向量索引 + 确定性图闭包，精准上下文供给
- **双层验收** — 阶段门禁 + 最终符合性验收
- **人在环路 / 人在环上** — 灵活的人类参与模式
